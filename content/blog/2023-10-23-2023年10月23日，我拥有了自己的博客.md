## 我们先建个房子

通过教程[基于Notion+Hugo搭建博客](https://yuanfoudev.github.io/posts/%E5%9F%BA%E4%BA%8Enotion-hugo%E6%90%AD%E5%BB%BA%E5%8D%9A%E5%AE%A2/)，耗时半小时，成功搭建了自己人生中的第一个博客。

最开始源于我在[即刻千古壹号的评论区](https://m.okjike.com/reposts/65362cc1aa7d4f2b304e386a?s=eyJ1IjoiNTc4MjFlMmJiYjk5YmExNDAwM2RlOTA4In0%3D)询问如何搭建博客，于是[大黑天](https://okjk.co/l1Gagh)给我推荐上面这个教程。

下班回到租房后，在笔记本电脑上跟着教程一步一步来，到最后一步时，立刻就困惑了。教程是这么说的：

> 你需要把你的仓库名（域名）添加到文件 `config/_default/config.toml` 中，替换里面的 `baseURL` 的值。比如你的域名是 `https://good.github.io`，你就需要把这个替换 `baseURL`的值。提交变更后你就可以获得一个基于 Notion 的博客了。此后你需要在 Notion 模板中写作，剩下的交给自动化即可。

我想了想，我并没有域名这个东西，顿时有种跟着食谱学做菜，到最后说请拿出你的烤箱（或你没有的厨具），合着前面都白做了。后面又想好像能用仓库名，但这要怎么操作？于是回过头看教程，在开头创建 Github 仓库时写道：

> 使用访问 github 模板地址，点击右上角“Use this template”按钮创建一个仓库，选择"public" 权限。  
> 有经验的话，可以将仓库重命名为“昵称.github.io”。

我作为编程纯小白，只学过用 Python 输出“Hello, world”的人，当然没有经验可谈，开始直接填写“昵称”为仓库名。于是回头将仓库名改为“昵称.github.io”，这样就可以直接用这个作为自己的博客网站了，后续有域名可以到 `config/_default/config.toml`更改使用。

于是在浏览器键入`liangsam.github.io`，独属于我的网站跃入眼帘，那一刻感到非常开心，终于拥有了自己的数字花园。

但问题是我的blog太丑，压根不能看（现在是已经改过的样子，尽管也很简陋），下一步的任务就是如何美化我的网站。

## 然后刷上墙漆

在这里刚看到教程里的blog页面简洁好看，于是点击页面底部的链接[hugo-paper](https://github.com/nanxiaobei/hugo-paper)。中间试了很多方法，折腾好几次，后来我直接把`hugo-paper`整个下载来，解压再上传整个文件夹到github仓库的themes里，再到`config/_default/config.toml`文件夹里修改最后一行为：

```toml
title = "梁某银的Blogs"
theme = "hugo-paper"
```

大概等了几分钟，我的主题就焕然一新，变成下面这样：

![](/images/2023/10/TinySnap-2023-10-24-10.04.59.png "换上 hugo-paper 后的博客")

再看一下[元否的工作坊](https://www.happyfou.com/)的博客页面，还有很多需要学习调整，目前就是毛胚房，上面的about页面、个人资料、右上角的社交媒体，都要摸索一下如何操作，想想就很开心。

![](/images/2023/10/TinySnap-2023-10-24-10.06.04.png "元否的工作坊")

现在你所看到的博客已经搭建得七七八八了，后续会写一个纯小白如何应用hugo主题的教程，因为在折腾的时候，也找到了些方法。

## 在地板上吹风

刚好最近在听知行小酒馆的播客 [E111 令人怦然心动的快乐（存钱）法](https://www.xiaoyuzhoufm.com/episode/653218bb206650fc6b68ea59) ，里面公众号也谈钱的主理人也大谈到，他买了新房后并没有专门做精装修，而是只装了个基础，打包旧家物直接搬到新家，在后面的生活中一点一滴去改善，缺了什么东西再去购买，慢慢增加生活的幸福感。

我也可以化用这个方式，先把一些旧文搬到这里，偷偷懒充当门面（啊不是），再去增加考虑如何把 blog 弄得更好看。反正现在作为博客的基础功能已经实现了：写文和发布，硬装完成，其他都能慢慢去调整。

而且用Notion作为写字平台，不用考虑太多要素，只要新建一页page，输入想写的东西，后面就能呈现到我的blog里面。

几经测试，发现内容同步比较慢，要多刷新几次，所以还是把精力放在如何输出更多内容上比较好。但还是比较开心，拥有了一座自己的小花园，后面可以慢慢来种下我想要的东西。

询问了ChatGPT，是因为 Hugo 是静态网站生成器，优势是速度快、安全性高、成本低（这倒是，我一分钱没花）、易于备份和还原、灵活性强（主题丰富）等特点，这样看来很适合我，低成本就构建了自己的博客，唯一的成本就是时间和电费了。

而且有了ChatGPT后，技术不再成为阻碍。在搭建过程中，有许多问题我直接询问ChatGPT，可以得到全面且清晰的答复，这真是太赞了！

好了，现在在我的博客房子里，坐着发呆，享受从窗外涌入的风，惬意自得。
