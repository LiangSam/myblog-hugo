手欠是要付出代价的。

我打开 App Store，看到 Anki 有更新提示，那一长串英文，尽管看不懂，但大概知道是重大更新，于是自信满满地点了更新，我在 iPhone 上斥资 168 元购买的 [AnkiMobile 就从 25.09 变成了 26.10](https://forums.ankiweb.net/t/ankimobile-26-10-is-out/74202)。没错，Anki 只针对 iOS 用户收费，网页、macOS、Windows、Android 俱是免费。

## Anki 为何这样？

打开新版本一看，首页的牌组从原来的列表变成了一个个圆角矩形卡片，硬生生制造出间隔；到处都是液态玻璃按钮，纯粹为了液态而液态。试问用 Anki 的人，谁在乎 UI？官方自己吹的新搜索语法，[在 Anki 论坛也遭到一致抨击](https://forums.ankiweb.net/t/undo-26-10-update/74279)，大家从各个方面都喷了个遍，甚至有人怀疑这是 vibe coding 的产物。

![新版本](https://img.liangmouyin.com/2026/11/536830898433fee2c12bcceb21a21c21.jpeg "看看复习页面顶部那些为了液态而液态的东西")

我吐槽了一通，本以为只能忍着，等下个版本修好，结果在那条帖子下面看到，论坛用户 julienvincenot [成功退回了旧版本](https://forums.ankiweb.net/t/undo-26-10-update/74279/55)。

原理在于 App Store 只给你最新版，但苹果的服务器上其实还留着历史版本。帖子里用的工具叫 ipatool，它能用你自己的 Apple ID 登录，下载你名下应用的任意一个历史版本，得到一个 `.ipa` 安装包。如果是 Anki，前提是你已经购买过。

他是让 ChatGPT 一步步带着装的，我则是在终端里和 Claude Code 一起弄的，前后没花多少时间，一次就成功了。

## 具体步骤

**1. 先同步、备份。**降级前先把 AnkiMobile 同步到 AnkiWeb，再备份一份数据。我电脑上也有 Anki，就算出问题也能从云端拉回来，风险不大。

**2. 安装 ipatool。**用 [Homebrew](/blog/why-how-homebrew-macos/) 一行就够：

```bash
brew install ipatool
```

**3. 登录 Apple ID。**

```bash
ipatool auth login --email 你的邮箱
```

第一次登录要等几分钟，然后输入密码和另一台设备上收到的验证码（比如我的是 MacBook Air）。密码和验证码全程只在自己的终端里输入，不要交给 AI。

**4. 找到 Anki 的 bundle ID。**

```bash
ipatool search AnkiMobile
```

得到的是 `net.ichi2.anki`。

**5. 列出历史版本，确认版本号。**

```bash
ipatool list-versions -b net.ichi2.anki --format json
ipatool get-version-metadata -b net.ichi2.anki --external-version-id <ID> --format json
```

第一条命令列出一串 external version ID，最新的在末尾；第二条命令查某个 ID 对应哪个版本号。挨个查有点慢，好在只要对比末尾相邻的几个就够了。我查到的是：

- `877897364` 对应 25.09
- `894175942` 对应 26.10

**6. 下载 25.09。**

```bash
ipatool download -b net.ichi2.anki --external-version-id 877897364 -o ~/Downloads/
```

输出里显示 `purchased=false`，没有产生新的购买。

**7. AirDrop 到 iPhone。**这是我最没底的一步，结果最简单：把 `.ipa` 直接隔空投送到手机上，点接受，它就覆盖安装了。不用数据线，不用 Apple Configurator，也不用先卸载，本地数据都还在。

**8. 收尾。**关掉 iPhone 的 App 自动更新，终端输入 `ipatool auth revoke` 退出登录。下载好的安装包我留着，以后误更新了，直接 AirDrop 一次就能装回来。

![旧版本](https://img.liangmouyin.com/2026/11/c4c6f74b6592aaf1cd82f9d3fdf130e4.jpeg "看到这个界面我的心也安定了下来")

ipatool 是第三方开源工具，要用 Apple ID 登录。我觉得可以接受，因为它只在本机运行，但你得自己判断。

## 小结

我一向不急着更新系统，[去年的 macOS 26 就没跟](/blog/why-i-refuse-to-update-macos-26/)，没想到在应用更新上栽了跟头。系统更新我还会犹豫几天，应用更新却从没当回事，本以为更新说明写得长，功能就更好用，实则不然。

现在我的规矩改成：更新常用应用前，先去论坛看一眼别人怎么说。再也不手欠打开 App Store，看看还有什么应用可以更新了。
