如何才能用好 macOS？

一般会有两类人有此疑问：一类是第一次使用电脑就是苹果系统，就像闯入一片陌生之地，所以只需要新手指南足矣；另一类是从 Windows 迁移过来，知道电脑的功能无非浏览器、文件管理、写代码、打游戏等等，于是自信闯入另一个系统，结果发现操作系统的底层逻辑不变，但很容易卡在基础操作和交互习惯上，[就像右利手突然被要求用左手来刷牙、用筷子一样](https://liangmouyin.com/blog/macbook-after-8-years-windows/)。

对于前者来说没有丝毫负担，可以从零上手；后者则要习惯快捷键和交互方式，譬如复制快捷键是 `⌘Command-C` 而不是 `Ctrl-C`，窗口关闭在左上角而非右上角，好在只要建立肌肉记忆后任督二脉就被打通，使用起来毫不费劲。

我已经使用 MacBook 一年有余，最初是新鲜而陌生，现在已经如臂使指，并且搭建不少自动化脚本（光写博客我就有 5 个 LaunchBar 动作），更别说现在折腾 AI，做几个 Vibe Coding 项目。我自认为已经迈过新手期，这一年也积攒一些关于 macOS 的用法，有的来自其他作者（主要是 Minja），有的是自己琢磨出来，所以现在我试着回答「如何用好 macOS」。

唯需注意，这不是一篇面向纯新手的文章，Finder 是什么、Dock 如何隐藏应用、截图快捷键、去哪里下载应用、触控板要怎么滑等基础问题就不赘述。如果你是第一次使用 macOS，还是建议找视频教程，遇到不会的就问大模型，等可以无碍使用一两天后，就算入门。

由于梳理起来颇费功夫，这个话题我拆分为两篇文章，一篇聊系统配置，另一篇说常用软件。本篇就以系统配置为主，我改过哪些系统设置后用起来更为顺畅，内容不会太多，毕竟 macOS 设置选项就这么多，都是在这螺蛳壳里做道场，诸君按需自取。

（由于 macOS 系统横跨多个版本，我目前以现在的 macOS 15.8.1 为主，其他系统版本的读者需要自己寻找设置。）

## 系统更新与锁屏

**关掉自动更新系统**。我的一贯观点是不自动更新系统，[去年的 macOS 26 我没有凑热闹](https://liangmouyin.com/blog/why-i-refuse-to-update-macos-26/)，今年即便推出了 macOS 27，我也没有在 MacBook 上更新——反而是在公司的设备更新了，但我同时用 macOS 27 和 macOS 15，并没有感受到本质区别。如果非要更新，应该是为了刚需功能，而不是界面。不过「系统设置-通用-软件更新-自动更新」里的「安装安全响应与系统文件」建议保留，它只管安全补丁，不会把系统升到新版本。

**触发角（Hot Corners）左下角设为锁定屏幕**。工作间隙用电脑需要起身离开工位时，我不喜欢被人端详屏幕上的东西，过去在 Windows 上我是习惯按 `Windows-L`，换到 macOS 后，固然也可以点击左上角的苹果图标然后锁屏，或者按快捷键 `⌃Control-⌘Command-Q`，但都比不上移动鼠标指针到一个角落。macOS 的触发角是鼠标指针移动到屏幕四个角落就会立即触发，我把左下角设为锁定屏幕，这样免于被人打量屏幕。

![触发角设置](https://img.liangmouyin.com/2026/11/cbb2a75c33d9f6e7a0ef31bfcd92f7ff.png)

## 触控板

**开启三指拖移**。这项设置默认是关的，而且藏在辅助功能里，不特意去找很难发现。打开后，三根手指放在触控板上滑动，就能拖动窗口或选中文字，不用再按住触控板，用起来很舒服。路径是「系统设置-辅助功能-指针控制-触控板选项」，打开「使用触控板进行拖移」，拖移样式选[三指拖移](https://support.apple.com/zh-cn/102341)。

![三指拖移](https://img.liangmouyin.com/2026/11/3b819c9dd9fbf45b180f12bb1ab18e5b.png)

**启用「用力点按」快速查词**。用过 MacBook 的触控板后我才知道它和 Windows 笔记本竟有天壤之别，且不说双指轻扫返回或前进，[单就「用力点按」的发现就让我非常喜欢](https://liangmouyin.com/blog/macbook-force-click-lookup/)，日常查生词我选中并右键「Look Up」，而在「系统设置-触控板-光标与点按-用力点按和触感反馈-查询与数据检测器」设为单指用力点按后，你会发现查词居然能如此丝滑，只要单指按住，然后用力，词典就会弹出来。

![](https://img.liangmouyin.com/2026/05/01903410a1c947abca8455286997f9e0.png "图源：苹果官网示例")

## 桌面与 Dock

**让桌面文件回归到文件**。[Minja 认为桌面应当具有工作台的属性](https://utgd.net/article/20246/)，现在的电脑桌面普遍只展现一个个硕大的图标，好像这样就能更快找到文件。然而图标本身毫无价值（乃至 Windows 桌面上的快捷方式，我几乎不会放），桌面可以当作收件箱处理截图、下载文件或者工作文档，只要稍加设置，桌面就能像文件抽屉那样一目了然。

![桌面文件配置](https://img.liangmouyin.com/2026/11/42dcb6de71981ce344d3bbfce9c05883.png)

设置方法：桌面空白处右键-查看显示选项（或按 `⌘Command-J`），把图标调到最小（约 24×24），文件名改到图标右边，间距拉大，文字尺寸 10 号，不断调整到你觉得舒适的位置。如此，桌面看起来就像列表视图，一眼扫去就是文件名。

**精简 Dock**。刚开机的 macOS 会将一堆图标安置到 Dock，有的人用了一年后还是和初始状态差不多，最好将部分不常用的应用取消常驻，保持 Dock 精简会让人极为舒适，尤其是你习惯到 Dock 切换应用而非 `⌘Command-Tab` 的情况下，鼠标指针移动过去就能找到。

![Dock示例](https://img.liangmouyin.com/2026/11/42b9c319aea8b04ecab3e3eab6338b12.png)

**让截图文件夹常驻 Dock**。我过去分享过[使用 macOS 自带截图的经验](https://liangmouyin.com/blog/2026-macos-screenshot-workflow/)，如何截图在这里暂且不谈，但即便你用的是其他截图工具，这个方法也能用得上。你需要把截图保存到固定文件夹，再把文件夹拖到 Dock，在 Dock 右键文件夹，排序方式为添加日期，视图为扇形，点击它后就能轻松调取截图。

![截图展开](https://img.liangmouyin.com/2026/07/fe84ce99e8014f03e3a54e15f138471a.png)

## 系统语言

**把系统语言改成英文**。或许你已经发现了，我的许多截图都是英文，我刚开始上手 macOS 一周后，就把系统语言设置为英文，因为 [macOS 的菜单和文件列表大多可以靠首字母定位](https://utgd.net/article/9227)，Minja 称之为「不用快捷键的快捷键」。一年多以来，并无不适或找不到设置的情况（搜索、翻译皆是工具）。

我自己觉得最舒服的是两个场景：一是用 LaunchBar 搜索应用或系统设置时，只要输入几个字母就能精准定位；二是下载文件要选择保存位置时，我想存到桌面，只需按一下 D，就能定位到 Desktop。如果不想全改，也可以在「系统设置-通用-语言与地区」里给单个应用单独指定语言，不必非此即彼。

系统设置大概就这些，它们有个共同点：[只需要做一次决定](https://liangmouyin.com/blog/simple-advice-works)，改完就不用再管。下一篇聊常用软件。
